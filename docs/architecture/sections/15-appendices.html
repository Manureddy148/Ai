This chapter is the reference layer of the document. It collects, in tabular form, every knob that governs the behaviour of er_pipeline.py (command-line flags, function parameters, lookup tables, model parameters and search grids), every line that main() writes to the run log together with the range in which each value indicates a healthy run, the exact byte-level format of the seven input files and the two output files, a glossary of the vocabulary used throughout the document, and a one-line index of every function in the script. 15.1 Appendix A: CLI and configuration reference

The pipeline exposes three command-line flags and no configuration file; every other setting is a Python default or a module-level constant. This is deliberate: a single script whose behaviour is fixed by its source is easier to audit under the reproducibility review described in Chapter 13 than one whose behaviour depends on an external configuration. Table 15.1 lists each setting with its owner, its default and the effect of changing it. Values marked const are module-level constants (regular expressions and lookup tables) that cannot be changed without editing the file.

Two conventions in the argument parser matter for operation. First, parse_known_args() is used instead of parse_args(), so the -f kernel.json argument that Jupyter injects when the script is run inside a notebook cell is ignored rather than rejected. Second, --data-dir is optional: when it is absent, find_data_dir() searches /kaggle/input, the working directory, its parent and dataset/ recursively for train_source1.tsv and returns the grandparent of the first hit, which is the directory that contains both train/ and test/.

Figure 15.1 places each log line on the main() timeline; Table 15.2 lists the lines in the order they appear, with the quantity each one reports and the range in which the value indicates a healthy run. The healthy ranges are design expectations derived from the metric and the algorithm, not measured results: the pipeline has not yet been run on the released data, and the measured values are to be filled from the run log in the results table of Chapter 10.

15.3 Appendix C: File format reference

All nine files are tab-separated text with a single header row and no quoting. The pipeline reads the seven dataset files with read_tsv(); the problem statement's rule that tabs are the only delimiter matters because both addresses and identifier lists contain commas. The examples below use illustrative identifiers and values in the format the problem statement specifies; they are not rows of the released data. Tab characters are shown as literal tabs inside the code blocks.

train/train_source1.tsv, train/train_source2.tsv, train/train_source3.tsv, test/test_source1.tsv, test/test_source2.tsv, test/test_source3.tsv
Four columns: entity_id (prefix S1-, S2- or S3- identifies the source), business_name, business_address, country. Any field other than entity_id may be empty. The problem statement designates Source 1 as the deduplicated reference source and gives no such guarantee for Sources 2 and 3; there is no separate source column, the prefix and the file are the only source indicators.

train/train_ground_truth.tsv
Two columns: source1_entity_id and matched_entity_ids, the latter a comma-separated list of S2/S3 ids, empty for a singleton. load_split() parses it into a dictionary of sets, dropping empty tokens. There is no test ground truth.

output/matching_results.tsv
Same shape as the ground truth: one row per test S1 entity in file order, matched_entity_ids de-duplicated by dict.fromkeys() and empty for predicted singletons. The singleton row is written as the id, a tab and a newline. This is the only file scored on the leaderboard.
output/candidate_pairs.tsv
Header source1_entity_id, candidate_entity_ids; one row per test S1 entity listing every S2/S3 record in the candidate table fte, i.e. exactly the rows scored by model.predict(). Matches are a subset by construction.
source1_entity_id	candidate_entity_ids
S1-00001	S2-00047,S2-00193,S3-00812,S3-00999
S1-00002	S3-00004
S1-00003
Design note. validate_submission.py (standard library only) enforces the rules the writer relies on: exact header, exactly two tab-separated columns per row, no quote characters, every test S1 id exactly once and no unknown S1 id, no empty or whitespace-padded token, S2-/S3- prefixes that exist in the test set, no duplicate token within a list, and matches ⊆ candidates when --candidate is given. A PASS (exit code 0) from the validator is the packaging gate (see Chapter 11); it does not compute the score.

15.4 Appendix D: Glossary

Table 15.3 defines the vocabulary used in this document. Where a term names a specific construct in the code, the construct is given.

Table 15.3 — Glossary of terms
TermDefinition
Entity resolution (ER)Determining which records, from one or more sources without shared keys, refer to the same real-world entity; here, linking S1 businesses to S2/S3 records.
Deduplicated reference sourceSource 1, in which each business appears once; justifies assigning every S2/S3 record to at most one S1 entity in decode_table().
BlockingCheap candidate generation that restricts expensive pairwise scoring to a small set of plausible pairs; implemented by block().
Candidate pairAn (S1 row, S2/S3 row) pair that survives blocking; one row of the table produced by block() and one entry of candidate_pairs.tsv.
Recall ceilingFraction of ground-truth pairs present among the candidates; the highest recall any matcher can reach. Logged as blocking recall ceiling.
Reduction ratio1 − (candidate pairs) / (|S1| × |S2+S3|); the fraction of the full cross product that blocking discards.
Blocking oracleMacro F0.5 obtained by predicting exactly the true pairs among the candidates; the score of a perfect matcher.
SingletonAn S1 entity with no true S2/S3 match. Scores 1.0 when the predicted list is empty and 0.0 otherwise.
Precision / RecallPer entity: true positives divided by predicted ids / by true ids.
Fβ, F0.5Weighted harmonic mean of precision and recall; F0.5 = 1.25·P·R / (0.25·P + R) weights precision twice as much as recall. Implemented by f05().
Macro averageThe metric is computed per S1 entity and averaged with equal weight, singletons included; macro_f05().
Open-set labelA categorical field whose test values may not appear in training (country: France). The pipeline never enumerates countries; unseen S1 labels fall back to all S2/S3 records.
NFKD foldingUnicode compatibility decomposition followed by dropping non-ASCII code points; turns Société into Societe. First step of basic().
Legal suffixA corporate-form token (Ltd, LLC, SARL) carrying no identity information; stripped by core_name() using the LEGAL set.
Core namename_c: the normalised name with legal suffixes removed; the primary text for blocking and name features.
DBA / alias marker"Doing business as" and equivalents (t/a, a.k.a., formerly) separating a legal name from a trade name inside one field; split by _ALIAS in name_parts().
ZIP, PIN, code postalUS 5-digit (+4) postal code, Indian 6-digit Postal Index Number, French 5-digit postal code; all captured by _postal.
House numberThe leading digit run of the normalised address (house); compared as a ternary state.
TF-IDFTerm frequency × inverse document frequency weighting of a text vector; here over character n-grams with sublinear_tf (1 + log tf) and min_df=2.
char_wbscikit-learn analyser producing character n-grams only inside word boundaries (words padded with spaces), so n-grams never span two tokens.
n-gramA contiguous sequence of n characters; the vectorisers use n = 2, 3, 4.
Cosine similarityDot product of two L2-normalised vectors; equals the sparse matrix product in topk_sparse() and the row-wise product in pair_cos().
L2 normalisationScaling a vector to unit Euclidean length; TfidfVectorizer does this by default.
Top-k / argpartitionSelecting the k largest scores per row without a full sort; np.argpartition is O(n) per row and returns the k best indices unordered.
Mutual nearest neighbourA pair that is the best candidate for both its S1 entity and its S2/S3 record on cos_full (cos_full_gap1 = cos_full_gap2 = 0, rank1 = rank2 = 1).
Gap featureA pair's feature value minus the maximum over its competitors on one side (*_gap1, *_gap2); zero for the best candidate.
Indel ratio (fuzz.ratio)Normalised similarity based on insertions and deletions, 0 to 100.
token_sort_ratiofuzz.ratio after sorting the tokens of both strings; order-insensitive.
token_set_ratioRatio over the intersection and differences of the token sets; tolerant of extra tokens on one side.
partial_ratioBest fuzz.ratio of the shorter string against any equal-length window of the longer one; substring matching.
Jaro-WinklerCharacter-transposition similarity with a bonus for a common prefix; n_jw.
Jaccard|A ∩ B| / |A ∪ B| over token sets (jacc()) or digit-run sets (num_overlap).
Gradient boosting / LightGBMAn ensemble of decision trees fitted sequentially to the gradient of the loss; LightGBM is the MIT-licensed implementation used by lgb.train().
GroupKFoldCross-validation that keeps all rows sharing a group key (i1) in one fold, so an S1 entity's candidates are never split between training and validation.
OOF (out-of-fold)Predictions for each row made by the fold model that did not train on it; the basis of the (thr, ratio) sweep.
Early stoppingHalting boosting when the validation loss has not improved for 100 rounds; the mean of the folds' best rounds, scaled by 1.1, sets the refit round count.
Threshold (thr) / relative ratio (ratio)The two decision parameters of decide(): absolute probability floor and minimum fraction of the best probability within the (S1, source) group.
Transitive closurePropagating matches along chains (if A~B and B~C then A~C); not applied here because the task is bipartite S1-to-S2/S3, but relevant to the roadmap (see Chapter 14).
Cross-encoderA transformer that reads both records jointly and outputs a match score; a roadmap option constrained to MIT/Apache-2.0 models of at most 8B parameters.
Feature importance (gain)Total loss reduction attributed to splits on a feature across all trees; printed for the top 15.
